## Инструкции для ИИ по задачам модуля куки

- Изменения текстов баннера и слоя представления: `AGENTS.md -> $django-152fz-cookie-banner`.
- Поведение исполнения, загрузка скриптов и контракт событий: `AGENTS.md -> $django-152fz-cookie-runtime`.
- Настройки/проверки конфигурации: `AGENTS.md -> $django-152fz-settings-checks`.
- Финальная проверка регрессий перед слиянием: `AGENTS.md -> $django-152fz-review`.
- Инструкция по добавлению новых языков: [../ai/languages.md](../ai/languages.md).
