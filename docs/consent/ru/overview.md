# Модуль согласий: обзор и текущее состояние

- [К общему разделу документации](../README.md)

## Назначение

Слой согласий покрывает жизненный цикл согласий 152-ФЗ:
- версионирование документов согласия;
- фиксацию выданных и отозванных согласий по потоку `purpose + document`;
- аудит изменений через события;
- работу с авторизованными и анонимными субъектами;
- просмотр и отзыв в самообслуживании.

## Что реализовано

- доменные модели ядра (`ConsentPurpose`, `LegalDocument`, `DocumentRevision`, `ConsentRecord`, `ConsentEvent`);
- сервисный слой для выдачи, отзыва и проверки статуса согласий;
- привязка согласия к конкретной редакции документа;
- режимы повторного подтверждения и повторного согласия;
- флаги возможностей для дополнительных контуров;
- публичный фасад `django_consent_152fz.service_api` для внешних интеграций.

## Что пока не реализовано

- производственная интеграция с Госключом (зарезервировано как будущее расширение).
- Подробности и причины вынесены в [Будущая интеграция с Госключом](./goskey.md).
