## Рекомендательная инвентаризация

Реализован минимальный рекомендательный сценарий инвентаризации:
- анализ известных интеграций (`CookieRegistryItem`) и входного списка;
- подсказка категории: `necessary` / `functional` / `analytics` / `marketing`;
- обязательный флаг ручной проверки для каждого результата.

Технические точки входа:
- `django_cookies_152fz.inventory.build_best_effort_inventory_hints(...)`;
- `django_cookies_152fz.inventory.build_inventory_hints_for_registry_items()`;
- команда `inventory_152fz_cookie_integrations`.

## Ограничения слоя

- это слой подсказок, а не автоматическая юридическая классификация;
- полноценный сканер страниц не является обязательной частью ядра;
- автоматический анализ всех таблиц БД и внешних CRM не входит в этот слой;
- запуск инвентаризации по умолчанию отключён: `enable_registry_hints=False`.
