`django-consent-152fz` — репозиторий с двумя независимыми Django-пакетами:

- `django-consent-152fz`: жизненный цикл согласий, редакции документов, аудит, самообслуживание субъекта, необязательный контур подтверждённых согласий, сервисный прикладной интерфейс.
- `django-cookies-152fz`: баннер куки, редакции политики, реестр исполнения, загрузка сценариев по согласию, аудит куки, гибкая настройка оформления и поддержка мобильных сайтов.

## Для чего проект

Проект помогает внедрить технический контур работы с согласиями и куки в контексте требований законодательства РФ о персональных данных.

Справочные ссылки:

- [Федеральный закон от 27.07.2006 N 152-ФЗ «О персональных данных» (КонсультантПлюс)](https://www.consultant.ru/document/cons_doc_LAW_61801/)
- [Обзор требований по персональным данным (Tilda Education)](https://tilda.education/articles-personal-data-law)

## Примечание о версиях пакетов

Версии `django-consent-152fz` и `django-cookies-152fz` могут отличаться и выпускаться независимо.  
Это отдельные модули без жёсткой взаимной зависимости по жизненному циклу, объединённые общей правовой направленностью 152-ФЗ.

## Установка

Только модуль согласий:

```bash
pip install django-consent-152fz
```

Только модуль куки:

```bash
pip install django-cookies-152fz
```

Оба модуля:

```bash
pip install django-consent-152fz django-cookies-152fz
```

Если нужен прикладной программный интерфейс:

```bash
pip install "django-consent-152fz[api]"
```

## Коммерческая поддержка

Проект распространяется как проект с открытым исходным кодом.

Авторы проекта могут оказывать коммерческие услуги по внедрению и адаптации данного пакета.

Возможные направления:

- техническая интеграция в существующие системы;
- адаптация под бизнес-процессы;
- настройка сценариев получения согласий и куки;
- проектирование и сопровождение внедрения;
- адаптация для сайтов, мобильных приложений и иных платформ;
- интеграция в существующие CMS и фреймворки;
- техническое и юридическое сопровождение по вопросам применения требований законодательства РФ о персональных данных (152-ФЗ);
- адаптация решений под различные юрисдикции;
- разработка и сопровождение индивидуальных решений.

Авторы допускают адаптацию идей и реализаций данного проекта для других языков, платформ, движков и технологических стеков при необходимости.

Сам пакет предоставляет технические инструменты и не гарантирует автоматическое соответствие требованиям законодательства. Ответственность за определение применимых требований и организацию процессов обработки персональных данных остаётся за оператором и его консультантами.

По вопросам внедрения и сопровождения можно связаться с авторами проекта.
