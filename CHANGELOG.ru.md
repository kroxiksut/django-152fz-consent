## [1.0.0] - 2026-06-02

Первый публичный выпуск обоих пакетов. Переиспользуемые Django-модули для
процессов 152-ФЗ: версионируемый жизненный цикл согласий с неизменяемым аудитом
и баннер cookie с runtime, учитывающим согласие. Дистрибутивы ставятся и работают
независимо — ни один не требует другого.

**Совместимость:** Python 3.10–3.12, Django 5.0 / 5.1 / 5.2 (LTS) / 6.0
(`Django>=5,<7`). Проверено в CI на Python 3.10 + Django 5.x и Python 3.12 +
Django 6.x, включая автономные (по одному пакету) и интеграционные прогоны.
Лицензия MIT. Коробочные/образцовые правовые тексты по умолчанию — на русском;
локализация интерфейса поставляется для русского (`ru`) и английского (`en`).
Ключи конфигурации, значения перечислений и публичный API — на английском.

### django-consent-152fz 1.0.0

Жизненный цикл согласий для проектов, обрабатывающих персональные данные людей в
России.

- **Правовые документы и редакции** — версионируемые правовые документы
  (`LegalDocument`) с неизменяемыми редакциями (`DocumentRevision`); согласие
  всегда привязано к конкретной редакции текста, на которую оно дано.
- **Цели обработки** — декларативная настройка целей обработки и связанных с ними
  кодов документов/полей; валидируется заранее по контракту кода
  `^[a-z][a-z0-9_]*$`.
- **Записи согласий и неизменяемый аудит-лог** — записи согласий и журнал событий
  только на дозапись по каждому факту выдачи/отзыва/изменения.
- **Самообслуживание субъекта** — шаблонный интерфейс, где субъект данных может
  просматривать и управлять своими согласиями.
- **Опциональный контур подтверждённых / бумажных согласий** — подключаемое
  приложение (`django_consent_152fz.verified_consents`) для верифицированных и
  бумажных согласий; режимы, связанные с Госключом, зарезервированы для будущей
  интеграции, но производственный клиент Госключа пока не реализован; extra
  `[pdf]` (ReportLab) генерирует PDF согласий.
- **Опциональный DRF API** — подключаемое приложение
  (`django_consent_152fz.api`) и extra `[api]`; монтируется только если
  приложение установлено и DRF импортируется.
- **Стабильный сервисный фасад** — `django_consent_152fz.service_api` —
  публичный API для внешних интеграций; слой `core.services` внутренний.
- **Единый контракт конфигурации** — всё поведение настраивается через
  `DJANGO_CONSENT_152FZ` (легаси-алиас `DJANGO_152FZ_CONSENT`) и `USE_API_152FZ`,
  нормализуется и проверяется в одном месте с ранними `ConsentConfigurationError`.
- **Включение возможностей наличием приложения** — опциональные части
  активируются добавлением их Django-приложения в `INSTALLED_APPS`, а не просто
  флагом.
- **Bootstrap на `post_migrate`** — примеры документов и стартовые цели
  заполняются после миграций, никогда на этапе импорта.
- Ядро зависит только от Django; DRF и ReportLab подключаются только через extra.

Установка: `pip install django-consent-152fz`
(`[api]` — DRF API, `[pdf]` — PDF для бумажных согласий).

### django-cookies-152fz 1.0.0

Баннер cookie и runtime с учётом согласия, намеренно автономный — содержит
собственный контракт интеграции и не импортирует слой согласий.

- **Баннер cookie** — готовый к рендеру баннер с гибким брендингом и мобильными
  вариантами оформления.
- **Запуск скриптов по согласию** — необязательные скрипты выполняются только
  после получения соответствующего cookie-согласия.
- **Runtime-реестр cookie** — реестр используемых сайтом cookie / категорий во
  время выполнения.
- **Версионирование редакций политики** — версионируемые редакции политики
  cookie; начальная редакция баннера заполняется на `post_migrate`.
- **Аудит cookie** — журнал решений по cookie-согласиям.
- **Автономность с опциональной интеграцией** — работает без пакета согласий;
  extra `[consent]` подключает `django-consent-152fz` для совместной работы.
- **Единый контракт конфигурации** — настраивается через `DJANGO_COOKIES_152FZ`
  (легаси-алиас `DJANGO_152FZ_COOKIES`).
- В основном механика не привязана к юрисдикции (категории, редакции политики,
  запуск по согласию, аудит); адаптация под другую юрисдикцию — в основном вопрос
  текстов и локали.

Установка: `pip install django-cookies-152fz`
(`[consent]` — интеграция с пакетом согласий).

### Общее для обоих пакетов

- **Двуязычность** — русский (`ru`) и английский (`en`) через Django `gettext`;
  добавление локали — это новая пара `.po`/`.mo` без изменений в коде.
- **Поставляемые AI-инструкции** — каждый дистрибутив содержит opt-in инструкции
  для AI-агентов в `<package>/ai/` (`AGENTS.md`, `AI_RULES.md`, `AI_CONTEXT.md`,
  `SKILLS.md`); автоматически не загружаются.
- **Независимые дистрибутивы** — собираются как отдельные wheel из единого
  src-layout монорепозитория; CI доказывает работу каждого без второго.

> Распространяется «как есть». Установка этих пакетов сама по себе не делает
> проект соответствующим 152-ФЗ — юридическую корректность текстов, документов,
> инвентаризации cookie и процессов обработки обеспечивает оператор.
