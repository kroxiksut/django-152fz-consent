# Base Site Guide (Before 152-FZ)

This file is used during the base demo stage before integrating the 152-FZ
package. The texts explain user flows without legal-heavy wording.

## Purpose Of Public Pages

- `Home`: briefly explains the training center demo and how to begin.
- `About`: describes the learning format and teaching approach.
- `Courses`: shows active programs and the entry point to signup.
- `Contacts`: provides a way to ask about schedule and course details.
- `Profile`: displays user account details and demo activity history.

## Purpose Of Forms

- `Course signup`: a two-step flow with final data confirmation.
- `Contact form`: a short request flow for training-related questions.
- `Registration`: account creation for personalized demo scenarios.

## Base Stage Boundary

At this stage, the site must operate with base course fixtures only, without
cookie layer integration and without consent texts.
