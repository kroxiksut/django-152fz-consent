# Согласия на обработку персональных данных (RU)

Этот файл — индекс материалов consent-flow. Подключение consent-flow выполняется
только после успешной проверки cookie layer.

## Длинные тексты по сценариям

- Запись на курс: `consent-course.md`.
- Обратная связь: `consent-contact.md`.
- Регистрация: `consent-registration.md`.

## Сообщения интерфейса

- Сообщения для сценариев без согласия и для подтверждения действия:
  `consent-messages.md`.

## Отказ от юридической консультации

Данные тексты приведены только для демонстрации технической интеграции и не
являются юридической консультацией.
