# Модуль согласий: границы области применения и ограничения

- [К разделу согласий](./README.md)
- [К общему разделу документации](../README.md)

## Что модуль делает

- Управляет жизненным циклом согласий по 152-ФЗ в приложении.
- Даёт проверяемую доменную модель и сервисный слой для основного сценария согласий.
- Поддерживает необязательные расширения (cookies, API, контур подтверждённых согласий, политики доступа).

## Что модуль не делает

- Не выполняет автоматическую регистрацию оператора ПДн.
- Не заменяет юридическую экспертизу документов и процессов.
- Не даёт универсальный правовой движок для разных юрисдикций.
- Не гарантирует готовые производственные интеграции со всеми внешними платформами верификации и вендорами.

## Практический вывод

Пакет — это технический фундамент для процесса работы с согласиями.
Юридические, организационные и отраслевые требования должны дополняться на стороне проекта.
