# Smoke Checklist: Django 5.x и Django 6.x

Этот чеклист единый для двух стендов:

- `demo/django5/` - эталонный стенд.
- `demo/django6/` - стенд сравнения с Django 5.x.

Порядок прохождения: сначала `django5`, затем `django6`.

## 1. Базовый сайт (без пакета 152-ФЗ)

### 1.1 Публичные страницы

- [ ] Открывается главная страница.
- [ ] Открывается страница `О центре`.
- [ ] Открывается страница списка курсов.
- [ ] Открывается страница `Контакты`.
- [ ] В навигации работают переходы между страницами.
- [ ] Переключение языка RU/EN работает на публичных страницах.

### 1.2 Курсы и запись

- [ ] Загружены общие курсы из `demo/common/fixtures/courses.json`.
- [ ] На странице курсов видны только активные курсы.
- [ ] Форма записи на курс открывается корректно.
- [ ] Двухшаговый flow записи работает от первого до второго шага.
- [ ] Успешная отправка заявки сохраняет запись в БД.
- [ ] Ошибки валидации отображаются пользователю.

### 1.3 Обратная связь и аккаунт

- [ ] Форма обратной связи открывается и отправляется.
- [ ] После отправки формы обратной связи создаётся запись `ContactMessage`.
- [ ] Отображаются сообщения об успехе и ошибке для обратной связи.
- [ ] Регистрация через `django-allauth` работает.
- [ ] Вход и выход пользователя работают.
- [ ] Страница профиля открывается для авторизованного пользователя.

### 1.4 Admin

- [ ] Доступ в Django admin возможен.
- [ ] Вход в admin под `admin/admin` выполняется успешно.
- [ ] В admin доступны модели курсов и заявок.
- [ ] Создание/редактирование курса через admin работает.
- [ ] Созданные заявки видны в admin.

## 2. Cookie Layer (после базового smoke)

### 2.1 Баннер и настройки cookie

- [ ] Cookie banner отображается на публичных страницах.
- [ ] Тексты banner доступны на русском и английском.
- [ ] Кнопка `Принять все` / `Accept all` работает.
- [ ] Кнопка `Настроить` / `Customize` работает.
- [ ] Открывается UI `cookie preferences`.
- [ ] Тексты `cookie preferences` доступны на русском и английском.

### 2.2 Изменение настроек

- [ ] Кнопка `Сохранить настройки` / `Save settings` применяет выбор категорий.
- [ ] Кнопка `Закрыть` / `Close` закрывает UI настроек без ошибки интерфейса.
- [ ] Настройки cookie сохраняются.
- [ ] Изменение настроек повторно доступно пользователю.
- [ ] После изменения настроек нет ошибок в консоли и в серверных логах.

### 2.3 Отсутствие регрессий базового сайта

- [ ] Публичные страницы продолжают открываться.
- [ ] Форма записи на курс продолжает работать.
- [ ] Форма обратной связи продолжает работать.
- [ ] Регистрация/вход/профиль продолжают работать.
- [ ] Admin остается доступным.

## 3. Consent-Flow (после проверки cookie layer)

### 3.1 Запись на курс

- [ ] Запись на курс с согласием проходит успешно.
- [ ] Запись на курс без согласия блокируется с понятным сообщением.
- [ ] Тексты согласий отображаются на RU и EN.
- [ ] Для записи на курс используются общие тексты из `demo/common/texts/`.

### 3.2 Обратная связь

- [ ] Обратная связь с согласием отправляется успешно.
- [ ] Обратная связь без согласия блокируется.
- [ ] Пользователь видит понятное сообщение о необходимости согласия.
- [ ] Для обратной связи используются общие тексты из `demo/common/texts/`.

### 3.3 Регистрация

- [ ] Регистрация с согласием проходит успешно.
- [ ] Регистрация без согласия блокируется.
- [ ] Поведение одинаково воспроизводится в Django 5.x и Django 6.x.
- [ ] Для регистрации используются общие тексты из `demo/common/texts/`.

### 3.4 Проверка согласий в admin

- [ ] В admin создаются записи согласий для записи на курс.
- [ ] В admin создаются записи согласий для обратной связи.
- [ ] В admin создаются записи согласий для регистрации.
- [ ] По каждой записи можно проверить связанный объект и статус согласия.

## 4. Протокол запуска проверки

- [ ] Сначала полностью пройден раздел 1 для Django 5.x.
- [ ] Затем пройден раздел 2 для Django 5.x.
- [ ] Затем пройден раздел 3 для Django 5.x.
- [ ] После этого те же разделы 1-3 пройдены для Django 6.x.
- [ ] Отличия между версиями занесены в `demo/notes/differences-5x-6x.md`.

Стенд: `demo/django5`  
Окружение: `django152fz-demo-dj5`

- `python manage.py migrate --noinput` — миграции применены, дополнительных нет.

  - форма обратной связи отправляется, сообщение сохраняется;
  - allauth: регистрация -> выход -> повторный вход работают;
  - профиль доступен после входа;
  - admin доступен, списки `Course`, `CourseSignup`, `ContactMessage` доступны;
