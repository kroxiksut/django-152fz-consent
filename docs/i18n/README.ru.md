# Вклад в переводы

Документ описывает правила вклада в локализацию RU/EN.

## Какие изменения можно вносить

- Добавление новых переводов пользовательских строк.
- Исправление существующих переводов.
- Выравнивание терминологии между документацией, шаблонами и интерфейсом.

## Обязательный порядок при изменении строк

Если изменение добавляет или меняет пользовательские строки (подписи, подсказки, тексты шаблонов, названия полей, варианты выбора и т.п.), в одном наборе изменений нужно:

1. Обновить исходные строки в коде/шаблонах/документации.
2. Обновить соответствующие каталоги `.po`.
3. Пересобрать `.mo`.
4. Проверить отображение RU/EN и отсутствие проблем с кодировкой.

## Требования к качеству

- Использовать только UTF-8.
- Не оставлять смешанные языки в финальных строках интерфейса.
- Сохранять согласованность юридической терминологии в контексте модуля.

## Где находятся файлы локализации

- Общие каталоги локализации демо: `demo/common/locale/*/LC_MESSAGES/`.
- Каталоги локализации пакетов: в соответствующих директориях пакетов.
