# Модуль согласий: импорт исторических данных

- [К разделу согласий](./README.md)
- [К общему разделу документации](../README.md)

## Назначение

Импортный слой предназначен для контролируемого переноса существующих данных согласий в модель ядра.

## Инструменты

- команда управления: `import_152fz_core_consents`;
- сервисный слой импорта: `core/importers.py`;
- адаптеры внешних систем: `imports/adapters.py`.

## Базовые принципы

- импорт выполняется отдельно от других модулей;
- предпочтителен `dry-run` перед фактическим применением;
- импорт сохраняет аудиторский контекст и не должен обходить доменные проверки сервисного слоя.

## Сопровождение

- изменения контракта импорта синхронизируются с [./configuration.md](./configuration.md), [./service-api.md](./service-api.md) и тестами;
- для вендор-специфичных сценариев используются расширяемые адаптеры, а не жёстко встроенная логика в ядре.
