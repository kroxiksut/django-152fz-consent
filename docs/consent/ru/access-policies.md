# Модуль согласий: политики доступа и область ресурсов

- [К разделу согласий](./README.md)
- [К общему разделу документации](../README.md)

## Назначение

Слой политик доступа дополняет жизненный цикл согласий ограничениями на действия по ресурсам.

## Рекомендованный контракт кодов ресурсов

Формат: `<module>.<resource_action>`, например:
- `crm.contact_update`
- `billing.invoice_export`
- `support.ticket_view`

Для дополнительной группировки допустимо использовать `extra_meta`, например:
- `{"module_scope": "billing", "subsystem": "invoices"}`

## Ограничения

- Слой политик доступа включается опционально через `enable_access_policies`.
- Он не заменяет базовую модель потоков `purpose + document`, а работает поверх неё.
- Проверки доступа должны опираться на сервисный слой и документированные правила политик.
