# Справочник базового сайта (до 152-ФЗ)

Этот файл используется на базовом этапе демо до подключения пакета 152-ФЗ.
Тексты предназначены для объяснения пользовательских сценариев без юридического
перегруза.

## Назначение публичных страниц

- `Главная`: коротко объясняет, что это демо учебного центра и как начать.
- `О центре`: описывает формат обучения и подход к занятиям.
- `Курсы`: показывает список активных программ и точку входа в запись.
- `Контакты`: дает способ задать вопрос по программе и расписанию.
- `Профиль`: показывает данные пользователя и историю действий в демо.

## Назначение форм

- `Запись на курс`: двухшаговый сценарий с проверкой введенных данных.
- `Обратная связь`: короткое обращение в центр по вопросам обучения.
- `Регистрация`: создание учетной записи для доступа к персональным сценариям.

## Ограничение базового этапа

На этом этапе сайт должен работать только с базовыми данными и фикстурами
курсов, без интеграции cookie layer и без текстов согласий.
