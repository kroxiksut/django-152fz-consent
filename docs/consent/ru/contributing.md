# Участие в разработке модуля согласий

- [К разделу согласий](./README.md)
- [К общему руководству по участию](../../../CONTRIBUTING.ru.md)

## Область

Документ относится к изменениям в `django-consent-152fz`: доменная логика, административные сценарии, сервисный прикладной интерфейс, документация и тесты.

## Типовые области изменений

- Логика жизненного цикла согласий (выдача, отзыв, статус, повторное согласие).
- Работа с документами и редакциями.
- Сценарии самообслуживания субъекта.
- Политики доступа и необязательный контур подтверждённых согласий.
- Сервисный прикладной интерфейс и транспортные адаптеры.

## Обязательные проверки перед PR

1. Добавлены или обновлены тесты под изменение поведения.
2. Обновлена документация в `docs/consent/en/*` и `docs/consent/ru/*`.
3. Проверена обратная совместимость публичных контрактов API (или явно описаны несовместимые изменения).
4. Проверено отсутствие побочного влияния на режим только-куки.

## Фокус тестирования

- Доменные и сервисные тесты операций согласий.
- Административные тесты по редакциям и политикам (если затронуто).
- Интеграционные проверки форм и маршрутов самообслуживания.

## Сопровождение документации

- Синхронизируйте англоязычную и русскоязычную документацию по пользовательскому поведению.
- При изменениях в контуре подтверждённых согласий обновляйте:
  - `verified-flow.md`
  - `goskey.md` (если поменялись границы интеграции)
  - `operations-admin.md`
