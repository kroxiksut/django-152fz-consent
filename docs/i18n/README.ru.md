# Вклад в переводы

Документ описывает правила вклада в локализацию RU/EN (и других языков).

## Какие изменения можно вносить

- Добавление новых переводов пользовательских строк.
- Исправление существующих переводов.
- Выравнивание терминологии между документацией, шаблонами и интерфейсом.

## Другие языки

Сейчас проект поставляется на RU и EN, но **переводы на другие языки
приветствуются** — как для документации, так и для строк интерфейса модулей.

- **Строки модулей:** добавьте каталог локали Django в
  `locale/<lang>/LC_MESSAGES/` с файлами `.po`/`.mo`.
- **Документация:** добавьте папку языка по модулю, например
  `docs/consent/<lang>/` и `docs/cookies/<lang>/`, по образцу `en`/`ru`.

Примечания:
- Русский текст — **канонический и юридически значимый** (контекст 152-ФЗ);
  все остальные языки, включая английский, информационные и не заменяют
  русский оригинал.
- Русский обязателен для любой пользовательской строки; остальные языки —
  по возможности, допустим частичный перевод.

## Форки и модификации

Проект распространяется как open source — форки вправе добавлять, изменять
или удалять языки, в том числе полностью убрать русский текст.

Учтите:
- Именно русский текст привязывает проект к юридическому контексту 152-ФЗ.
  Форк, удаливший его, утрачивает эту юридическую основу, и допущения
  о соответствии закону, действующие для оригинала, к нему не относятся.
- Авторы оригинала предоставляют проект «как есть» и **не несут
  ответственности** за форки и изменённые копии, их переводы и юридическую
  пригодность любых формулировок, которые те распространяют.

## Обязательный порядок при изменении строк

Если изменение добавляет или меняет пользовательские строки (подписи, подсказки, тексты шаблонов, названия полей, варианты выбора и т.п.), в одном наборе изменений нужно:

1. Обновить исходные строки в коде/шаблонах/документации.
2. Обновить соответствующие каталоги `.po`.
3. Пересобрать `.mo`.
4. Проверить отображение RU/EN и отсутствие проблем с кодировкой.

## Требования к качеству

- Использовать только UTF-8.
- Не оставлять смешанные языки в финальных строках интерфейса.
- Сохранять согласованность юридической терминологии в контексте модуля.

## Где находятся файлы локализации

- Общие каталоги локализации демо: `demo/common/locale/*/LC_MESSAGES/`.
- Каталоги локализации пакетов: в соответствующих директориях пакетов.
